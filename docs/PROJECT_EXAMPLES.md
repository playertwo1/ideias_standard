# Exemplos de projetos

`examples/` guarda referências mínimas de projetos que usam o template.

Cada exemplo deve conter somente:

1. um README com propósito e fase;
2. um manifesto pequeno;
3. o link da fonte real.

Não copie código, secrets, histórico operacional ou o Runner para o template.
Atualize um exemplo somente quando ele ensinar uma melhoria reutilizável.
