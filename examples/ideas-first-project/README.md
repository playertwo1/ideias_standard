# Primeiro projeto: Idea

Exemplo mínimo de uso do Gold Standard.

- Produto: app local-first para transformar ideias em especificações verificáveis.
- Fase registrada: F01 documental; Android/F02 ainda bloqueado por `G01 = NOT_RUN`.
- Papéis: Antigravity = Builder; Codex = Auditor; usuário = Product Authority.
- Fonte completa: `https://github.com/Sora-bluesky/ideas`.

Este diretório é apenas uma referência compacta. O estado real permanece no
repositório do projeto e não deve ser copiado para o template.
